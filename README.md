# 🌿 The Hidden Cost of Convenience

### Are We Paying More Than We Think?

**The Hidden Cost of Convenience** is a student project that explores the hidden environmental, social and financial consequences of modern convenience. It highlights how everyday activities like online shopping, food delivery, single-use products and excessive dependence on digital services can create unexpected costs.

The project aims to promote awareness, responsible consumption and sustainable lifestyle choices.

---

## 📌 Project Overview

Modern life has become easier with technology and instant services. We can order food, shop online and access almost everything with a few clicks.

However, these conveniences may also contribute to packaging waste, unnecessary spending, environmental pollution and overdependence on technology.

This project explores these issues and presents practical solutions for building a more responsible and sustainable future.

## 🚀 Installation and Setup

Follow these steps to run the project locally.

**Step 1: Clone the Repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the Project Folder**

```bash
cd The-Hidden-Cost-of-Convenience
```

**Step 3: Open in VS Code**

```bash
code .
```

**Step 4: Run the Website**

- Open `index.html` in Visual Studio Code.
- Right-click on the file.
- Select **Open with Live Server**.

The website will open in your default browser.
